# Hexfront

A turn-based strategy game for phones and PCs: build an empire on a hex map, then watch everyone's orders collide at once. Civilization meets Red Alert, playable with one thumb.

**Play it:** https://ghotib.github.io/hexfront-play/

- Works in any modern browser, offline once loaded; add it to your home screen to install it.
- Everything runs on your device against computer opponents. No account, nothing uploaded.
- `hexfront.html` in this repo is the same game in a single file, for Android or desktop browsers without a network.

This repo holds only the built game. The source is private.
